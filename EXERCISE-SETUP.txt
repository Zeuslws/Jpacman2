Assertion experiment:
The initial source is preserved as evidence/BoardTest-experiment.java.txt.
With -ea, nullSquareAt fails at construction with AssertionError:
"Initial grid cannot contain null squares". With assertions disabled,
squareAt(0, 0) returns null and the experiment's isNull check passes.
The final regression tests EXPECT assertion failures and therefore pass
with -ea. They are intentionally different from the exploratory version.
To repeat the exploratory run, use a disposable copy of this project,
replace its src/test/java/nl/tudelft/jpacman/board/BoardTest.java with the
saved experiment source, then run:
  ./gradlew test --tests nl.tudelft.jpacman.board.BoardTest --rerun-tasks
  ./gradlew -I evidence/disable-assertions.gradle test --tests nl.tudelft.jpacman.board.BoardTest --rerun-tasks
The first command intentionally fails; the second passes. Do not replace
the final regression file in the submission copy.
